# AI-Native AI Engineering

This repository contains project instructions and deliverables for the AI-Native AI Engineering course.

## Week 1

Week 1 introduces agent decisions under uncertainty.

Students select one problem. They discuss the problem with humans. They design and test an agent. They publish the results as an IJCAI-style course preprint.

Read the [Week 1 project instructions](week1/deliverables/week1-ai-native-shipping-sprint.md).

## Week 2

Week 2 extends the same agent with beliefs, information value, and cost.

Students keep their Week 1 problem. They add hidden states and belief updates, measure what each piece of evidence is worth in bits, price what it costs to obtain, derive a decision threshold from the cost of being wrong, run an experiment comparing policies, and analyse their own failures.

Read the [Week 2 project brief](week2/week2-probabilistic-view-of-ai-agents.pdf) (PDF, LaTeX source in [`week2/paper/`](week2/paper/)).

There is no deadline on deliverables. See [`week2/README.md`](week2/README.md).

Two optional Claude Code skills ship with it: [`week2/skill/readiness/`](week2/skill/readiness/SKILL.md) interviews you and writes a roadmap for where you actually stand, and [`week2/skill/coach/`](week2/skill/coach/SKILL.md) walks you through the build stage by stage.

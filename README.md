# AI-Native AI Engineering

This repository contains project instructions and deliverables for the AI-Native AI Engineering course.

## Week 1

Week 1 introduces agent decisions under uncertainty.

Students select one problem. They discuss the problem with humans. They design and test an agent. They publish the results as an IJCAI-style course preprint.

Read the [Week 1 project instructions](week1/deliverables/week1-ai-native-shipping-sprint.md).
